# YONLAB

気になった話題を、Webニュース風の記事としてまとめる個人制作サイトです。

## About

このサイトは、ChatGPTを利用して制作しています。

記事制作では、配信などを見ながら自分で内容をメモし、
そのメモをもとにChatGPTで記事構成・HTML・CSSなどを作成しています。

生成された内容はそのまま公開せず、
元の情報と照らし合わせながら内容の訂正・加筆・調整を行っています。

なお、現在公開している記事では、
配信動画そのものをChatGPTに読み込ませて記事を生成しているわけではありません。

## AI usage

主に以下の用途でChatGPTを使用しています。

- 記事構成・文章の作成
- HTML / CSSの作成
- レスポンシブデザインの調整
- 表現や構成の修正
- デバッグの補助

記事の題材選定、元情報の確認、事実関係の訂正、
最終的な掲載判断などは人間が行っています。

## Disclaimer

YONLABは非公式の個人制作サイトです。
掲載対象となる人物・団体・サービス等とは関係ありません。

公開情報や配信内容をもとに制作していますが、
内容の正確性を保証するものではありません。
