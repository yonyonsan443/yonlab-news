# ABC Music News / YONLAB

ABCさんと作詞作曲家・神成秋人さんの配信内容を、ネットニュース風にまとめるための静的HTMLサイトです。

## 構成

- `index.html` — 記事本文
- `style.css` — レスポンシブ対応のニュースサイト風CSS
- `assets/` — 将来、配信スクリーンショットやOGP画像を置く場所

## 方針

- 日本のWebニュース媒体でよく見られる、カテゴリ・公開時刻・大見出し・共有ボタン・目次・本文・サイドバーという情報設計を参考にしています。
- 特定サイトのロゴ、ソースコード、固有画像、固有CSSはコピーしていません。
- ページ内に「非公式ファン記事」である旨を明記しています。

## ローカル表示

ファイルを直接ブラウザで開くか、簡易HTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000/` を開いてください。

## GitHub Pages

1. GitHubで空のリポジトリを作成
2. このディレクトリ内のファイルをリポジトリ直下へ配置
3. Settings → Pages を開く
4. Deploy from a branch を選択
5. `main` / `/ (root)` を指定

## 更新候補

- 実際の配信スクリーンショットを、権利・掲載可否を確認したうえで追加
- 配信URL・配信日時・楽曲リンクを追加
- OGP画像とfaviconを追加
- トップページと記事一覧を追加
- 記事をJSON/Markdownから生成する仕組みに変更
